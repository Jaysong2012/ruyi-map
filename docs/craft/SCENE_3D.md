# SCENE_3D — 3D 程序场景制作手册（D 管线）

`render_scene.mjs`（Three.js builder 系）：机制/尺度/关系的「诚实代码图解」。
program 索引与 spec 字段见 `packages/scene3d/PROGRAMS.md`；terrain_block 专册见 `TERRAIN_BLOCK.md`。

## 〇、什么时候用 3D 程序渲染

- **适用**：机制与影响可视化（轨道/尺度/穿越/结构拆解）、真实素材穷尽后的诚实图解、需要「一镜到底穿尺度」的史诗航程。
- **红线**：程序渲染不得伪装成观测、实拍或历史影像；它是「诚实的代码图解」。
- **判断式**：这个画面是在**解释一个机制/尺度/关系**吗？是→3D 值得做；只是想要「好看」→先找真实素材。
- **判死线：观众的真实感阈值=日常经验**。太空/轨道/光影观众无日常参照系，几何精确即过关；
  **水/流体/侵蚀/泥沙/火/烟/布观众天天见，没有 CFD 级模拟的手工关键帧永远一眼假**——
  核心证据是「日常经验内的动态物理过程」的题材，找不到真实素材锚就不立项。

## 一、总架构：画面的三层来历

### 1. 真实素材层（真实感的地板）
NASA/USGS 等公开测绘贴图裹几何体：行星表面、地形 DEM、实拍影像。程序画不出木星大红斑那种细节——
**真实感由素材决定地板，由工艺决定天花板**。
- 行星贴图：`assets/space/textures/`（2k 起步，hero 主体上 8k）
- 弱光远景行星 2k 足够；近景 hero 必须高分辨率，宁可用超分救赎。

### 2. 程序化层（数学算出来的像素）
没有素材或素材低质时，逐像素/逐顶点生成。**已验证配方**：
- **燃烧太阳**（ShaderMaterial）：分形噪声 fbm(坐标,时间)+域扭曲+高频沸腾米粒
  +临边昏暗 `pow(ndv,0.5)`（真实物理）+边缘火舌。**不要**加 BackSide 菲涅尔壳=气泡感。
- **行星环**：RingGeometry UV=平面投影，1024² canvas 逐像素：环带亮度分段表
  （C/B/卡西尼缝/A/恩克缝）+1D 值噪声细纹+色温微漂+内外缘软出 `min(1,min(u,1-u)*18)`；
  配自发光 MeshBasicMaterial（Standard 材质=黑团）。
- **装饰元素**（轨道圈/轨迹线/辉光/星空）：圆环几何、drawRange 生长线、径向渐变 sprite、
  随机点云（种子固定）。

### 3. 运动与摄影层（导演发生的地方）
**整个片长里没有一个关键帧手摆，全是 t 的解析函数**：
- 天体位置 = `a0 + t×speed×gain`，速度按 `0.045×(7/R)^1.2`（开普勒感：内快外慢）
- 航天器 = 参数曲线 `trajCurve.getPoint(tk(t))`；借力会合点由数值求解反推行星初相
- 摄影机 = 相位制（锚点序列+smooth 插值），**每个相位边界都是潜在闪点**
- 改任何运动参数后：先数值复算受影响的事件点，再快渲探针验证

## 二、渲染管线

```
node packages/scene3d/render_scene.mjs <scene.json>
  └─ 无头 Chromium（playwright-core，--use-angle=metal GPU）
       └─ 加载 assets/three/three-0.185.1.js（window.DoppelThree）
       └─ builder 搭建世界，暴露 window.__render(t)：给定 t 摆出该时刻全貌
  └─ 逐帧截图 PNG（motionBlur 时每帧采 N 子帧）
  └─ ffmpeg 合成 mp4（crf 可控）
```

- `motionBlur {samples:3,shutter:0.5}` 快速运动**标配**，成本=帧数×3
- `keepFrames:true` 保留 PNG 供 QA/复用
- builder 契约：async 函数返回 `setState(t)`；纹理走内置服务器同源路径；**禁 Math.random**
  （要随机用固定种子的 LCG/噪声表），相机/形变全部是 t 的解析函数

**确定性是资产**：同一 t 永远同一画面 → 才能「只改一环、其他一像素不动」地迭代，才能数值 diff 回归。

**报错可见性**：page console/pageerror 直通 stderr；物体消失+辉光残留=白团假相=shader 编译失败，
`#include` 必须独占一行、模板字面量内 GLSL 换行写 `\\n`。**凡「就绪超时但无任何报错」先查
内联 script 被字面 `</script>` 截断**（哪怕在注释里）。

## 三、迭代工作流（改动不过夜）

1. **改参数前先数值复算**：凡影响事件点（会合/穿越/相位边界）的改动，先用同一套数学求解新锚点
2. **快渲探针**：`fps:2 + 全时长 + canvas 960×540 + keepFrames` → 40 帧覆盖全片；只抽受影响时间窗
3. **联系表必须烙时间戳**（glob 字母序≠时间序）
4. **构图对比一律数值 diff**（PIL ImageChops），禁跨分辨率肉眼比对
5. **送审前自查到终审粒度**：毫秒级听音+像素级看框；放大裁剪关键区域逐一过
6. 全量渲染 → 抽帧 QA → 送审

## 四、epic_journey 参数字典（最通用的穿越模板）

史诗航程/穿越边界：`母星起飞→行星擦肩→边界膜穿越→深空拉远`。别名 `voyager_helio`。**改数据不改骨架**。

| 参数 | 含义 | 备注 |
|---|---|---|
| `sun{r,tex,color,burn,legacy}` | 太阳：半径/贴图/色调/燃烧强度(0=关)/回退旧材质 | burn=1 标准 |
| `bodies[]` | 行星表：`n/R/r/tex/tilt/a0/rot/bump/sheen/hero/heroTex/ring/atm` | override 整表替换（浅合并），改一颗也要给全表 |
| `launchBody` | 出发行星 | 轨迹第一点应在该行星表面附近 |
| `orbitGain / orbitPow` | 公转增益 / 内外衰减指数 | 肉眼可辨基准：pow1.2+gain2.5；**改了必重算会合 a0** |
| `trajectory[[x,y,z]...]` | 航程控制点（CatmullRom） | 借力点要贴着对应行星轨道面过 |
| `camKeys[[k,pos,look]...]` | 机位关键帧（k∈[0,1]） | 相位边界±0.3s 连续帧验证 |
| `phaseK[5]` | 五相边界 | 改 camKeys 通常要联动复查 |
| `speed{pow,gain,slingshots[{at,amp,width}]}` | 船速曲线 | slingshot 幅度宁小勿大 |
| `membrane{R,scale,color} / null` | 边界膜（Fresnel+冲击波）；null=纯巡航 | 穿越点数值求交自动算 |
| `travelMs` | 航程时长（缺省=片长） | |

## 五、审美红线（每条都是一轮否决换来的）

1. 相位边界锚点必须连续；改相位必抽边界连续帧
2. 事件点数值求交，禁手估坐标
3. 透明物体 renderOrder 显式分层
4. 禁屏幕恒定尺寸；近远双模互补混合
5. 速度脉冲要缓（幅度减半宽度加倍起步）
6. 不可见之物画边界不画本体
7. 贴图所有轴向 falloff；深空暗画面上任何硬边都穿帮
8. 设计感装饰一律删，剩下的全是叙事本体；加元素前答「它改变了什么」
9. 相机永远稳；冲击感由特效+音效承担
10. 打光基调：PointLight `0xfff2d8×4.2 decay0.3` + Ambient `0x32405c×0.95`；emissive 保暗面可读
11. 快速运动必上运动模糊
12. shader include 独占一行；白团先查编译
13. 菲涅尔壳裹发光体=气泡；调参三轮不如删
14. 弱点光场景装饰件用自发光材质，Standard=黑团
15. 改公转速率必重算会合点（数值求解，非手拍）
16. 构图对比数值 diff；探针快渲验证不过夜
