# TERRAIN_BLOCK — 全省地形沙盘制作手册（E 管线）

`render_scene.mjs` 的 `terrain_block` program：真实 DEM 整块+卫星贴图+程序收边的大面积海拔叙事
（「平原薄边 → 高原高墙」的落差肉眼可见）。spec 字段全表见 `packages/scene3d/PROGRAMS.md`。

## 一、核心判例（改数据不改骨架）

1. **一套程序多 spec 分段服务全片**：同一 DEM/掩膜只构建一次，多镜头=多 scene spec 改参数
   （`timeline{fly,drv,end}` 时刻表、`driveOnly/flightBack/diveIn/profileOnly` 模式、
   `hero/chips/stationRings` 信息层开关）。
2. **有效垂直夸张比**：EXAG/SCALE 组合，**28=可信高墙档**；45 下真实坡度=刀片墙判死。
   贴图「条码感」是深切河谷真实纹理在夸张下的固有代价。
3. **4K 渲染=spec.layout 基准+deviceScaleFactor**（viewport 布局恒定+DOM 文字 3x 栅格化；
   zoom 方案对 canvas 不生效判死）；labelSprite/剖面卡纹理 ×SC、scale 除 SC 抵消。
4. **收边正解**：HDS BFS 径向衰减（EDGE=10 格 smoothstep 倾伏，局部高山地块需 22-26）
   +衰减带贴图渐隐+**只画全内三角**（MASK 混合三角的卫星贴图 90° 壁 UV 拉伸=刀片墙真根）；
   垂直裙（任何形态）全判死。衰减写进 HDS=全下游（采样/AO/金线/路线）联动。
5. **轨迹线语义分层**：航迹=信息层（depthTest false+实心不透明+drawRange 72 索引段对齐——
   半透明细管闪烁源全判死）；自驾线=贴地层（贴地点+受光材质+emissive 保色）。
6. **同 program 并行渲染=打架**（共享帧目录+端口）：必串行。
7. **视觉模型放大误报定罪法**：单帧放大审视会把 DOM 大字读成「拉丝伪影」——
   判词复现必须配无元素对照帧+列跳变量化。

## 二、两级镜头语言与总揽工艺

1. **两级镜头分工**：L1=省域 3D 地形定场（震撼，pitch ~61°，EXAG 28）；
   L2=俯视 88° 平面观感路线环（信息图，核心是环不是山）。分 spec 渲染+后期无缝拼接
   （拼接差 <2px 帧差验收）。海拔夸张比分镜头走但保持全片统一
   （EXAG 28 下俯视相机必须抬高校正——渲前数值重验）。
2. **省形掩膜**：标准省界 ring+小半径闭运算（只消栅格锯齿）；
   「省∪邻省+大圆盘」会抹平全部地理凹湾——总览级判死。分项目 terrain 目录
   （共享 DEM/贴图，mask 项目自建）。
3. **卫星贴图拼缝**：瓦片直拼的批次色差线，修法=分块 RGB 增益归一
   （向全图均值对齐 clamp 0.85-1.15）+跨缝增益平滑插值（纯增益过渡不碰纹理）。
4. **渲前机位数值验证**（复刻渲染器 HDS 场）：LOS 通视+关键点 NDC 投影+画幅四角覆盖——
   定机位零渲染成本；EXAG/掩膜变化后必须重验。
5. **像素审计三误报源**：①直线连首尾对弧线段必误报→路线感知折线（沿中途站连线）；
   ②固定高度假设在高 EXAG 下偏差数百 px→用管真实高程 HY(alt)+EXAG/100；
   ③视觉模型缩略图细线误报→全分辨率像素探针+局部裁剪目检复核。
6. **总揽信息层减法**：标签收敛锚点站（noLabel 单站跳过）+wpLabelScale 高空缩放
   +lx/lz 错位+wpLabelHold 参数化常亮+stationRings 关（总览不做光圈墙）；
   driveOnTop=路线环信息层化（depthTest:false+renderOrder 5，恒可见，默认 false 保贴地语义）。
7. **站点弹出 hero 语言**：hero 照片从站点标记放大浮现（白边卡片+弹性过冲）→停留
   （站名 chip+日期大字）→收回地图——「点击地图查看详情」交互隐喻。

## 三、信息层与时序

- **信息层几何纪律**：主几何（管线/路线）所有派生浮起统一参数（`p.routeLift ?? 0.012`）——
  主线 EXAG/100 类浮起在近机位=悬空几十 px、与支线断差=衔接中断感；
  信息层标记（箭头/光圈）lift 必须 > 主几何半径（埋管判例）；
  标记尺寸按最远机位 ≥0.24 场景单位定，白色芯+深描边（线色同芯不可读）。
- **箭头场**：`p.driveArrows` / `rl.arrows`——线头过后点亮+呼吸脉冲；
  `rl.label` 线画完浮现；`rl.onTop` 概览路线过山过隧道恒可见。
- **短窗镜头纪律**：站点标签 wt=frac*(T-0.4) 在 trim < 标签时刻的镜头里=「亮起即切走」闪现——
  L1 定场镜头一律 `wpLabels:false`，站点信息由 L2 信息镜头承担。
- **段级渲染→合成分层不变式**：任何时刻改变（driveKeys/ringAt/标签/箭头窗）都要过
  「trim 窗与事件时刻交」审计——事件出现在 trim 外=不可见或闪现。

## 四、flood_block（水位上涨沙盘，terrain_block 派生）

高程场连续网格 + 水面 Three.js 平面 mesh（y=水位，地形自然遮挡）+ 城市海拔钉。
geojson 格子 fill=马赛克判死；水面必须是连续平面不是填色格子。
