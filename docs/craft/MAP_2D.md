# MAP_2D — 2D 地理可视化制作手册（A 管线）

geo_bake 三件套：真实卫星底图 + 精确边界/路径/云系的知识可视化（台风/洋流/战事地理/事件播报）。

## 总纲

地图片的本质是**数据可视化**：观众信任建立在「每根线、每个点都在它该在的地方」。
**坐标是命脉**——错位一次，全片可信度归零。
方法论不变：**真实感找素材（卫星底图/真实云系），精确性写代码（坐标/边界/信息层）**。

## 一、投影实证法（铁律）

**docstring、请求窗、记忆、上一版代码——全都不可信。坐标参数只允许两个来源：**

1. **瓦片对齐反推**（有拉取代码时）：GIBS epsg4326 瓦片按网格对齐，请求窗只是意图。
   `x0=int((lon0+180)//DEG)` 取整后真实窗=瓦片边界——`DEG(zoom)=288/2^zoom`
   （Z6=4.5°, Z7=2.25°，512px/瓦片）。
   例：请求 `100 12 135 40` → 真实窗 `lon99-139.5 lat9-40.5`（`90-11×4.5=40.5` 不是 45——
   算错这一位就是「东北日本轮廓出现在广东」）。
2. **地标两点定标**（只有图片时）：程序提海陆分割（海=蓝≥绿且暗，陆=绿>蓝+15），
   找可识别地标（台湾/海南/半岛）的像素包围盒，两点（最好三点）对经纬度拟合 `lat_top` 与 `px/°`。
   **不许肉眼叠图循环论证**——裁窗与画线用同一错误映射时，错位的线看着也「贴合」。

**epsg4326 = 等距圆柱，x/y 统一 px/°。** 凡是算出「双比例」的，一定是窗参数错了。

## 二、坐标 sidecar 制度（防再错的工程闭环）

`map_bake.py` 烘焙底图时把**真实窗/px_per_deg 写进 `<底图>.geo.json`**——
**渲染器一律从 sidecar 读坐标参数，不许在代码里手写窗常数**（手写=下一次错位）。
`base_image` 模式（已有底图只加边界）必须给 `window_real`（实证窗），脚本校验窗比例与图片尺寸一致才放行。

## 三、管线三件套（全部 spec 驱动）

```bash
# ① 底图+边界：GIBS 静态图层 mosaic（或 base_image 复用）+ 行政边界
#    （DataV 省界/国界、NaturalEarth 外国界、十段线——包内 data/ninedash.geojson），产物=底图 PNG + geo sidecar
ruyi-map bake map <spec.json>

# ② 云图拉取（台风/云系题材）：GIBS 葵花9 红波段→灰度帧（公有领域，署名 JMA/NASA GIBS）
ruyi-map bake himawari <TIME> <out.jpg> <lon0 lat0 lon1 lat1>

# ③ 云系层：云图→云 mask RGBA 层（亮度阈值带 (L-lo)/(hi-lo) clip + 高斯柔边，海陆零色差），
#    warp 对齐底图坐标系（读 geo sidecar），半尺寸存储
ruyi-map bake cloud <spec.json>
```

真彩化：红波段灰度图按「蓝海绿陆白云」上色（云白/海深蓝/陆绿）。

## 四、云系层叠加模式（讲天气的片子必须看得见天气本体）

- mask 只提云（`lo=90, hi=200, blur=6`）：云系贴底图、海陆背景全透明，零色差、叙事诚实（当日真实卫星云系）。
- **动云全程制**：全生命周期真实卫星序列（生成→巅峰→登陆→死亡）按叙事节拍锚定索引连续播放，
  台风本体全程活着；三张静图+透明度包络=云是死的，且拍间无云裸奔段是「天气预报感」来源。
- **溶解纪律（防闪）**：①稀疏帧（帧距 >3h）全程溶解=破碎重影闪烁源，改
  「驻留 + 末窗快溶」（每步 80-90% 时长驻留单帧、末 0.25s 快溶）=延时摄影节奏；
  ②帧距 >1 天的生成史快切整段砍掉（1s 切 3 次两天距帧=闪，宁可单帧驻留）；
  密集帧（30min-1h）驻留制下仍流畅。锚跨度多帧按等分拆步。
- **云色压暗不压 mask**：亮白云系是白字溶解元凶——mask 用原始亮度提（阈值语义不变），
  贴图 RGB 单独压暗（×0.82）。
- 云在底图层，路径/卡片/信息层永远在上（composite 顺序：底图→云→vig→信息层 overlay）。

## 五、镜头与信息层（地图版动效语法）

- 相机窗口插值（`camera:[{at,west,south,east,north}...]`）必须覆盖全片时长；
  轨迹 `kind` 语义：observed=实测实线 / forecast=预测虚线 / uncertain=低置信虚线。
- 渲染前自动验收底图亮度：`meanLuma>=48` 且亮像素占比 `>=35%`，不合格直接终止——
  地图是事实证据层，默认保持明亮清楚；禁止全画幅黑色遮罩，文字对比只加局部描边/柔边底板。
- 「高清」首先验收海岸线、行政边界、中文地名和事件位置一眼可辨，然后才看像素尺寸；
  final=原生 3840×2160 渲染，不放大 720p 成片。
- 预报机构写全名放固定图例；多机构预测=「预报分歧」，主情景须注明依据，不得虚构概率；
  地名只表示地理位置。

## 六、PIL 绘制纪律

- PIL 11 的 `ImageDraw.line(width=)` 端点是方帽——长线交接处必须补 `joint="curve"` 或端点圆，
  否则折线拐角露缝（alpha 通道实锤过）。
- 半透明叠加一律先画 RGBA 层再 `alpha_composite`，禁多次 `paste(mask=)` 叠 alpha（每次都重预乘，色偏）。
- 文字描边用 `stroke_width`+`stroke_fill`（PIL≥8 原生），禁四方向偏移手描（字重失真）。
